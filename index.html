0DLSS 5 Neural Rendering이 뭔가

NVIDIA가 공개한 신세대 기술로, DLSS 업스케일러가 만든 프레임 위에 신경망 모델이 미세 디테일(모공, 천 직조, 금속 표면, 나뭇잎 등)을 다시 합성해 얹는 기능입니다. 공식 지원은 RTX 50 시리즈 + 최신 드라이버이지만, 이 가이드는 OptiScaler 포크를 써서 그 이전 카드에서도 돌리는 방법을 다룹니다.

한 줄 요약: 업스케일러(DLSS)가 "커다란 그림"을 그리면, NR 모델이 그 위에 "잔손질"을 얹는 겁니다. 프레임을 부드럽게 하는 게 아니라 디테일을 합성하는 기술이라, 효과는 확대하거나 움직임 속에서 더 드러납니다.

3어떤 도구를 쓸까 — 옵티스케일러를 우선하세요

결론부터: DX12 게임이면 옵티스케일러 NR 하나로 시작하세요. 실제 사용 기준 성능 체감이 가장 좋았던 조합이고, 프레임 생성·업스케일러·오버레이까지 전부 하나에 들어 있습니다. DX12가 아닌 게임도 대부분 옵티스케일러를 유지·혼합해서 쓸 수 있습니다 — 방법은 아래 4번 섹션에 있습니다.

DLSS5 NR을 돌리는 방법은 여러 진영으로 갈립니다. 검증 결과를 신뢰도와 함께 정리합니다(2026-09-02 기준, 전부 오프라인/싱글 전용).

4내 게임에서 DLSS5가 되나? — API별 옵티스케일러 사용법

추천 원칙: 되는 한 옵티스케일러를 끝까지 쓰세요. 게임 API가 달라져도 대부분 옵티스케일러를 유지할 수 있고, 설정이나 도구만 바꾸면 됩니다.

✅ DX12 — 설치 그대로, NR 켜기. 추가 작업 없음 (체감 최고 조합).
✅ Vulkan — v0.1.2부터 네이티브 지원. 설치 그대로, NR 켜기.
⚠️ DX11 — 옵티스케일러 유지 + 오버레이 왼쪽 위 업스케일러를 "FSR 3.X w/Dx12"(또는 XeSS w/Dx12)로 변경해야 NR이 켜집니다. DLSS를 브리지로 통과시킬 수는 없어서입니다.
❌ DX9 / DX10 / 32비트 — 옵티스케일러 단독으로는 불가 → dlss5-launcher가 DXVK 등 변환기를 자동 구성해 NR을 돌립니다(이때는 옵티스케일러를 제거해 충돌을 피하세요).

"내 게임은 되나?"에 대한 답입니다. NR 자체는 DLSS가 받는 프레임이 필요하고, DLSS는 DX11/DX12/Vulkan만 지원합니다 — 그래서 오래된 API는 변환 계층이 끼어듭니다.

DX9 게임의 진실 — 어떻게 되는 건가

DLSS 자체는 DX9 입력을 받지 못합니다(NVIDIA DLSS SDK 공식: D3D11/D3D12/Vulkan만). 그래서 DX9 게임은 DXVK(D3D9→Vulkan) 또는 dgVoodoo2(D3D9→D3D11)로 먼저 번역한 뒤, 번역된 Vulkan/D3D11 프레임에 NR을 얹습니다.

  • 실측 선례 있음: dlss5-launcher가 DX9 32비트 게임 3종(Bully, Resident Evil Revelations 2 + DXVK — 1800프레임/64fps, Saints Row 2 + dgVoodoo2)에서 NR 구동을 체인 로그로 보고. DX10(Just Cause 2)도 DXVK 1.10.3 특정 구성으로 실측.
  • 단, 자체 보고: 독립 검증은 부족하고, 같은 게임도 변환기에 따라 크래시가 갈립니다(README에 크래시 비교표 존재). 게임별 시행착오를 각오하세요.
  • DXVK는 온라인 게임과 충돌 — DX9 경로는 싱글 구작용이라는 뜻이기도 합니다.
  • RTX 20/30은 패치 DLL의 FP16 경로라 비용이 큽니다 — UI가 미리 알려주는 게 정상입니다.

6설치 (10분)

  1. 게임 폴더 찾기 — 실행 파일(.exe)이 있는 폴더. Steam이면 .../steamapps/common/게임이름/bin64 같은 하위 폴더일 수 있음 (exe 옆이 정답).
  2. 포크 zip 전부 추출 — 위 ①의 zip을 그 폴더에 풉니다. OptiScaler.dll, nvngx.dll_dlssnr.dll(포워더), OptiScaler/ 폴더, setup_windows.bat가 보이면 OK.
  3. 로더 이름 선택 — setup_windows.bat 실행 → 안내에 따라 이름 선택:
    • 보통 DX12 게임: dxgi.dll (기본값)
    • 같은 폴더에 ReShade(dxgi.dll)가 이미 있으면: version.dll 선택 (ReShade와 공존하는 공식 방법)
  4. 모델 DLL 복사 — 준비한 nvngx_dlssnr.dll(~165MB)을 같은 폴더에 넣기. 파일 하나 차이 주의: nvngx.dll_dlssnr.dll(110KB 포워더, zip에 포함)과 헷갈리지 말 것.
  5. 게임 실행 → Insert 키 → OptiScaler 오버레이 → DLSS Neural Rendering → Enable 체크 → "Running — X ms per frame" 초록 글자 확인.
setup_windows.bat 주의: 이미 OptiScaler가 설치된 게임 폴더에서 실행하면 "구버전 발견 → 삭제?" 질문이 나옵니다. 지우고 싶지 않으면 No를 누르거나, 수동으로 OptiScaler.dll을 원하는 이름(version.dll 등)으로 바꾸고 bat을 건너뛰어도 됩니다. 바꾼 이름이 정답입니다.

7켜고 확인하기

  • 오버레이: Insert (기본) → DLSS Neural Rendering → Enable Neural Rendering 체크
  • Running 표시 = 가동 중. 경고 문구가 보이면: "model would not initialise" = 카드/드라이버/DLL 문제, "not found" = 파일 위치 문제
  • Keybinds에서 "Neural Rendering" 키를 지정해두면 오버레이 없이 게임 중 토글 가능 — 강력 추천
  • 효과 확인은 Compare (Side by side / Wipe) + Zoom 2.5~3배로 하세요. 풀프레임 육안 비교로는 차이가 잘 안 보이는 게 정상입니다

9어두운 화면 노이즈 잡기 (실전 순서)

  1. Keybinds에서 NR 토글 키 지정 → 끄고/켜고 빠르게 비교
  2. Compare → Split 켜서 좌우 대조 (가장 정확한 판정)
  3. Intensity 1.0 → 0.7 → 0.5 단계적으로 하향 (즉시 적용)
  4. 그래도 심하면 Paper white 0.8 ↔ 1.2 탐색
  5. 스타일이 과하면 Style → Natural / Cinematic
  6. 디테일이 죽었다 싶으면 Detail strength 0.8~0.9
  7. 마음에 드는 값 찾으면 Save Settings 필수
참고: NR에는 전용 디노이즈 노브가 없습니다(코어링·시간축 누적은 시도 후 제거됨). 노이즈는 위 레버 조합으로만 관리합니다. 게임이 HDR로 렌더링하는 경우 v0.1.2부터 exposure texture를 읽어 색이 맞춰지므로, v0.1.2 이상 사용을 권장합니다.

10문제 해결

"the model would not initialise"
모델 DLL이 카드에 맞지 않음. RTX 20/30/40이면 패치 빌드(SF-v2 등)인지 확인 — 순정 310.8.0.0은 RTX 50 전용이며 Ada에서 FAIL_PlatformError가 납니다.
"nvngx_dlssnr.dll was not found"
모델 DLL이 게임 실행 파일과 같은 폴더에 없는 것. 한 글자 차이 주의: nvngx.dll_dlssnr.dll(포워더, 110KB)와 nvngx_dlssnr.dll(모델, 165MB)을 착각하기 쉽습니다.
화면이 통째로 초록색
구버전(v0.1.1 이하)의 HDR 색 변환 문제. v0.1.2 이상으로 업데이트하세요. (HDR 모니터 유무와 무관하게 게임의 프레임버퍼 방식이 변수입니다)
프레임 생성(FG) 켠 뒤 부팅 크래시
오버레이 저장 시 FG Input/Output 조합이 게임과 맞지 않으면 크래시가 날 수 있습니다. 저장 전 FG 설정이 정상 부팅되던 조합인지 확인, 크래시 시 OptiScaler.ini의 [FrameGen] 섹션을 직접 수정(원래 값으로)하면 복구됩니다.
ReShade와 같이 쓰기
ReShade가 dxgi.dll을 점유 중이면 OptiScaler를 version.dll로 설치(공식 권장 조합)하면 공존됩니다. ReShade 애드온(RenoDX DLSS5 등)과 포크 NR을 동시에 켜면 이중 NR이 되니 둘 중 하나만 쓰세요.
