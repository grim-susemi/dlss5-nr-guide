1Neural Rendering 개요

NVIDIA가 공개한 신세대 기술로, DLSS 업스케일러가 만든 프레임 위에 신경망 모델이 미세 디테일(모공, 천 직조, 금속 표면, 나뭇잎 등)을 다시 합성해 얹는 기능입니다. 공식 지원은 RTX 50 시리즈 + 최신 드라이버이지만, 이 가이드는 OptiScaler 포크(포크 = 원본 OptiScaler를 특정 기능용으로 개량해 배포하는 파생 빌드)를 써서 그 이전 카드에서도 돌리는 방법을 다룹니다.

한 줄 요약: 업스케일러(DLSS)가 "커다란 그림"을 그리면, NR 모델이 그 위에 "잔손질"을 얹는 겁니다. 프레임을 부드럽게 하는 게 아니라 디테일을 합성하는 기술이라, 효과는 확대하거나 움직임 속에서 더 드러납니다.

내 게임에서 DLSS5가 되나? — API별 사용법

추천 원칙: 되는 한 옵티스케일러를 끝까지 쓰세요. 게임 API가 달라져도 대부분 옵티스케일러를 유지할 수 있고, 설정이나 도구만 바꾸면 됩니다.

✅ DX12 — 설치 그대로, NR 켜기. 추가 작업 없음 (체감 최고 조합).
✅ Vulkan — v0.1.2부터 네이티브 지원이며 현행 v0.2.0에서도 동일하게 작동하니, 설치 그대로 NR만 켜면 됩니다.
⚠️ DX11 — 옵티스케일러 유지 + 오버레이 왼쪽 위 업스케일러를 "FSR 3.X w/Dx12"(또는 XeSS w/Dx12)로 변경해야 NR이 켜집니다. DLSS를 브리지로 통과시킬 수는 없어서입니다.
❌ DX9 / DX10 / 32비트 — 옵티스케일러 단독으로는 불가 → dlss5-launcher가 DXVK 등 변환기를 자동 구성해 NR을 돌립니다(이때는 옵티스케일러를 제거해 충돌을 피하세요).

"내 게임은 되나?"에 대한 답입니다. NR 자체는 DLSS가 받는 프레임이 필요하고, DLSS는 DX11/DX12/Vulkan만 지원합니다 — 그래서 오래된 API는 변환 계층이 끼어듭니다.

DX9 게임의 진실 — 어떻게 되는 건가

DLSS 자체는 DX9 입력을 받지 못합니다(NVIDIA DLSS SDK 공식: D3D11/D3D12/Vulkan만). 그래서 DX9 게임은 DXVK(D3D9→Vulkan) 또는 dgVoodoo2(D3D9→D3D11)로 먼저 번역한 뒤, 번역된 Vulkan/D3D11 프레임에 NR을 얹습니다.

  • 실측 선례 있음: dlss5-launcher가 DX9 32비트 게임 3종(Bully, Resident Evil Revelations 2 + DXVK — 1800프레임/64fps, Saints Row 2 + dgVoodoo2)에서 NR 구동을 체인 로그로 보고. DX10(Just Cause 2)도 DXVK 1.10.3 특정 구성으로 실측.
  • 단, 자체 보고: 독립 검증은 부족하고, 같은 게임도 변환기에 따라 크래시가 갈립니다(README에 크래시 비교표 존재). 게임별 시행착오를 각오하세요.
  • DXVK는 온라인 게임과 충돌 — DX9 경로는 싱글 구작용이라는 뜻이기도 합니다.
  • RTX 20/30은 패치 DLL의 FP16 경로라 비용이 큽니다 — UI가 미리 알려주는 게 정상입니다.

1설치 — 3단계 절차

받고(GET), 놓고(DROP), 켜기(ENABLE). 시작 전에 위 2. 요구사항을 먼저 확인하세요. 도구 전체 비교는 위 3. 도구 선정, 수동 설치 참고는 아래 2. 부록에 있습니다. API별 호환(DX11 · DX9 · DX10 · 32비트)은 ① 시작 탭 하단의 API 안내에 있습니다. 손 설치가 귀찮으면 ① 시작 탭 판단표의 자동 설치 도구(선택)를 보세요.

이 포크의 새 기능(PR #2): 구버전에서 빠졌던 Model resolution 200% 슬라이더(200%까지 모델 슈퍼샘플링)가 복원됐고, D3D12 게임용 Hold frame(현재 프레임을 얼려 고정한 상태에서 비교하는 검수 컨트롤)도 새로 들어왔습니다. 들어간 릴리스: grim 포크 최신(Latest, 영어판) · 한국어판. 한국어 UI와 키별 해제 버튼은 한국어판 zip에 포함됩니다. 기본값은 여전히 100%이고, 200%는 모델 비용이 약 4배(비용 = 비율의 제곱)라 프레임 여유가 있을 때만 쓰세요.

1프레임 생성 경로 · 카드 세대별 (RTX 20/30 · 40 · 50)

게임 메뉴의 FG/MFG 배율을 여는 길은 카드 세대가 갈립니다. FG 세부 옵션(FG Input · FG Nvngx · Ratio)의 조작법은 ④ NR · 옵틱 옵션 탭의 "프레임 생성 (FG)" 섹션에 있습니다.

RTX 20 / 30 · 네이티브 MFG 없음, 변환 기반 FG

20/30번대는 MFG 언록 대상이 아닙니다(언록은 40번대 전용). 게임과 상황에 따라 아래 중 하나로 프레임 생성을 돌립니다.

  • 게임에 FSR 3 FG가 있으면: FG Input에서 FSR 3.1 / 3.0 FG를 고르고 인게임 FSR-FG를 먼저 켭니다
  • DLSS FG 게임이면: FG Nvngx를 Nukem's로 바꿔 DLSSG 호출을 FSR3-FG로 변환. Nukem's는 FSR3 FG 자체가 2x이므로 고배율은 Enabler·Combo 사용. 이미 OptiScaler가 깔린 게임이면 위 합본 zip을 같은 폴더에 덮어풀기 + setup_windows.bat 재실행(구버전 삭제 질문에 기존 로더 유지 또는 정리)으로 교체 가능합니다
  • FG 자체가 없는 게임이면: OptiFG(Upscaler)가 최후 수단. HUDless 자원이 없어 UI 잔상이 생길 수 있습니다
  • NR은 패치 모델 DLL로 동작하되 20/30은 FP16 경로라 비용이 큽니다. UI가 미리 알려주는 게 정상입니다
RTX 40 · 언록 후 게임 메뉴 배율 (2x~6x)

현행은 내장 언록 하나입니다. Multipass_MFG를 썼다면 아래 첫 번째로 끝나고 애드온 설치가 필요 없습니다.

  • Multipass 내장 언록(권장): 오버레이에서 Unlock MFG on RTX 40 체크 후 재시작하면 게임 메뉴 배율이 열립니다. 성공 판정은 초록 상태줄("both gates patched" + 커널 컨테이너 수 — 기기·드라이버에 따라 숫자가 다름)으로 확인합니다
  • MFGUnlock 애드온: ReShade 애드온(renodx-mfgunlock.addon64)이 40번대에 잠긴 배율 선택지를 게임 메뉴에 열어줍니다. 구 애드온 방식의 설치·실측 기록은 ⑤ 애드온 · 문제해결 탭에 접어 두었습니다. 내장 언록을 쓰는 지금은 볼 필요 없습니다
  • 공통 전제: nvngx_dlssg.dll 310.9(합본에 동봉) + 인게임 프레임 생성 ON
RTX 50 · 네이티브 MFG, 언록 불필요

50번대(Blackwell)는 MFG가 네이티브라 언록 체크나 애드온이 필요 없고, 게임 메뉴의 배율을 그대로 씁니다. 모델 DLL도 드라이버에 포함이라 별도 다운로드가 없습니다(패치 DLL이 필요한 건 20/30/40뿐).

  • FG Input은 게임 상황에 맞게(DLSS 게임이면 DLSSG via Nvngx), Ratio는 Default(게임 설정 따름)가 정답
  • Force Dynamic MFG는 Blackwell 전용 기능: 모니터 주사율에 맞춰 배율을 자동 오가는 동적 MFG(자세한 건 ④ 탭의 Force Dynamic MFG 카드)

2Neural Rendering 상세 설정

Enable Neural Rendering 기본: OFF ON 유지

NR 마스터 스위치. 게임 중 토글용 키를 Keybinds → "Neural Rendering"에 지정해두면 오버레이 없이 즉시 끄고/켤 수 있습니다 — 어두운 장면 비교에 필수급.

Model resolution (Cost) 기본 100% · 범위 25~100% 포크 복원: 200%까지 (PR #2)

모델이 연산하는 내부 해상도 비율. 프레임 자체는 안 줄고 모델 비용만 변합니다(비용은 비율의 제곱).

  • 100% 이하 — 비용 절감 레버. 프레임이 부족하면 80%까지 내려보세요
  • ⚠️ 100% 초과 슈퍼샘플링(모델을 원본보다 크게 돌리는 품질 여유 레버)은 포크 복원으로 200%까지 열립니다(PR #2, VRAM 상승). 아래 Passes도 고화질 담당입니다
Passes · Lift the pass limit · Per pass 기본 1 (native) · 상한 5 → 해제 시 30 Multipass판 신규 — 가장 비싼 옵션

모델을 한 프레임에 몇 번 돌릴지. 1이면 학습된 그대로(초록색), 2~3이면 자기 출력 위에 덧칠(주황색), 4~5는 과잉 영역(빨강). 비용이 정확히 배수 — 5패스면 모델 5번 값, 매 프레임. 올리기 전에 Detail strength·Intensity·Model resolution을 먼저 써보세요.

  • Lift the pass limit — 체크하면 슬라이더 상한이 5에서 30까지 열립니다(보라색). 30 근처는 게임이 사실상 멈추니 실용 영역은 5 이하. 3을 넘기면 아래 Highlight guard도 같이 올려야(패스 수 ≈ 가드 배수) 추가 패스가 잘리지 않습니다
  • Per pass — 패스가 2 이상이면 나타나는 패스별 미세 조정(2패스째는 약하게 등). 건드리지 않은 패스는 위 전체 설정을 그대로 따릅니다
Run inside the upscaler · Run before the upscaler (둘 다 실험적) 기본 둘 다 끔 Multipass판 신규

모델을 어디서 돌릴지 바꾸는 실험 옵션. 평소엔 둘 다 끄고 쓰세요(끄면 업스케일 끝난 화면에서 동작 = 지금 검증된 방식).

  • Run inside the upscaler — 업스케일러를 반으로 쪼개 그 사이에 모델을 끼웁니다(재시작 필요). 화면이 작을 때 싸게 돌리는 방식. Enlarged by에서 확대 담당(DLSS/FSR/XeSS 등)을 고릅니다
  • Run before the upscaler — 업스케일 전 작은 화면에서 먼저 돌립니다(값이 싸짐). 단 카메라 움직일 때 반짝임이 생길 수 있는 미검증 영역
Enlargement 기본: Matched residual · 100%에선 회색(선택 불가)

모델을 100%보다 작게 돌릴 때, 작은 결과물을 화면 크기로 어떻게 올릴지. 100%에 두면 회색으로 잠기고 둘은 같은 동작이니 신경 쓸 필요 없습니다. 100% 미만에서 색이 어긋나면 Matched residual 쪽이 정답인 경우가 많습니다.

Detail strength TransferStrength · 기본 1.0 · 범위 0~2

모델의 그림으로 얼마나 갈아타는지. 0 = 업스케일 원본 그대로(비트 단위 동일), 1.0 = 모델 그림 채용, 2.0 = 모델 너머 과잉 보정. 디테일 체감의 핵심 레버이며 2.00은 과잉 영역이라 1.0~1.2 권장.

Colour strength ColourStrength · 기본 1.0 · 범위 0~1

0 = 게임 원본 색을 유지하고 밝기 판단만 모델에게 맡김, 1 = 모델의 색까지 채용. 0이면 효과의 절반이 사라지므로 1.00 유지 필수. 색이 이상하면 0.8로 하향.

Intensity 기본 1.0 · 범위 0~2

모델 내부 파라미터의 강도. 어두운 화면 자글거림(노이즈) 1차 조절판 — 슬라이더를 놓으면 적용됩니다(Deferred). 0.5~0.6이면 노이즈가 눈에 띄게 줄고 2.0은 과잉(콘트라스트 과다).

Local structure / Local tone 기본 1.0 · 범위 0~2

디테일 구조와 톤의 세부 강도. Intensity로 해결 안 되는 미세 조정용.

Skin structure (-1 = Local 따름) · Auto skin mask

피부 렌더링 전용 구조 강도. -1은 "끔"이 아니라 "Local structure 값을 따라감"이라는 뜻. Auto mask는 피부 영역 자동 인식. 캐릭터 얼굴이 인위적으로 보일 때만 조정.

Model preset (재시작 필요) / Style (즉시)

Preset(Default/1/2/3)은 모델 생성 시 고정되어 변경하면 재시작이 필요. Style: Default(콘트라스트·조명 강조, 과채도 가능)/Natural(피부톤·톤 원본 유지)/Cinematic(광택·과처리 억제).

White point from (어디서 흰색 기준을 가져올지) 기본: The game's own exposure Multipass판 — 3개 중 고르기

  • XeFG (입력) — 선택 불가. 입력용으로 미구현되어 있으며, XeFG는 FG Output(출력)에서 선택하십시오

  • ⚠️ 게임과 맞지 않는 입력으로 바꾸고 Save하면 부팅 직후 검은 화면 크래시가 날 수 있음 (예: 붉은사막은 Nvngx 외의 값에서 Streamline 플러그인 충돌로 부팅 15초 뒤 크래시 보고). 크래시 나면 OptiScaler.ini의 [FrameGen]을 직접 되돌리면 복구됨

관련 ini 키: UpscaleRatioOverrideEnabled(강제 켜기) · UpscaleRatioOverrideValue(강제 비율) · QualityRatio*(모드별 비율).

Output Scaling 선택 옵션, ON도 안전

DLSS 체인이 전부 끝난 뒤 최종 프레임을 한 번 더 확대하는 옵션입니다. 체인 뒤에서만 작동하니 체인을 건드리지 않고, 체감 가능한 부담도 없습니다.

검증된 예시: 렌더 1706x960 → 화면 2560x1440, Quality 모드에서 1.50으로 3840x2160 출력, 82fps로 잘 돌아갑니다. 이 사용자의 ini는 Enabled=true, Multiplier=auto, Downscaler=0 조합입니다.

지원 범위는 Dx12 게임과 Dx12 백엔드(게임을 Dx12 방식으로 돌리는 통로)를 쓰는 Dx11 게임입니다. Multiplier는 0.5~3.0(기본 1.5)입니다.

Downscaler는 확대 방식 선택입니다. 0 FSR1(AMD의 확대 알고리즘), 1 Bicubic, 2 Catmull-Rom, 3 Lanczos2, 4 Lanczos3, 5 Kaiser2, 6 Kaiser3, 7 MAGIC이며 기본은 FSR1. Bicubic부터 Kaiser까지는 주변 픽셀로 새 픽셀을 계산하는 보간(중간값 채우기) 방식의 이름입니다.

참고: NR 모델이 그리는 해상도(WorkingScale, 슈퍼샘플링 = 필요보다 크게 그려서 줄이는 방식)는 별개의 모델 내부 수단으로, 이 두 옵션과는 독립입니다.

관련 ini 키: Enabled(켜기) · Multiplier(배율, auto 허용) · Downscaler(방식 번호).

1ReShade + 애드온 설치

  1. ReShade 설치: 공식 다운로드에서 설치 시 애드온 지원(addon support) 빌드를 선택하세요. 애드온 API는 ReShade 5.0에서 처음 들어왔고, 전체 애드온 지원 빌드만 .addon64 파일을 불러옵니다. 설치 후 게임 폴더에 dxgi.dll(ReShade64)이 보이면 OK. 자세한 API 문서는 reshade.me/docs, 소스는 ReShade GitHub.
  2. OptiScaler 동거: ReShade가 dxgi.dll을 점유 중이면 OptiScaler 포크는 version.dll로 설치(공식 권장 조합).
  3. 애드온 복사: .addon64(ReShade 애드온 파일 형식)를 게임 실행 파일과 같은 폴더에 넣기. 받을 곳: RenoDX discussions, iMMERSE.
  4. 확인: 게임 실행 → ReShade 오버레이(게임 화면 위에 뜨는 ReShade 메뉴) → Add-ons 탭에서 애드온 이름 확인.
ReShade 애드온과 포크 NR 동시 주의: RenoDX DLSS 같은 NR 애드온과 포크 NR을 동시에 켜면 이중 NR이 되니 둘 중 하나만 쓰세요.

MFGUnlock — 40번대 MFG 열기 실측: 4x 성공

ReShade 애드온(renodx-mfgunlock.addon64 v0.3)이 40번대에 잠긴 배율 선택지를 게임 메뉴에 열어줍니다. 옵티는 통과만 시키고 배율 결정은 게임에 맡기는 구조.

출처: mavismmg/MFGAdaUnlock-RenoDx (MIT) — 원작 ImDreamt/Dreamt 포크 + STALKER 2 호환 수정. RenoDX·ReShade 기반. 설치 파일: Releases의 renodx-mfgunlock.addon64 (v0.3 SHA-256 83D5EF4D…066EB). NVIDIA 비공식 — 디스크 수정 없이 실행 중 메모리에만 패치, NVIDIA 파일 재배포 없음.

  • 옵티: FG Input = DLSSG via Nvngx · FG Nvngx = None · Override DLSSG Ratio = Default (예: 붉은사막 실측값)
  • 애드온: Enabled 켬 · ForceMultiplier = 0(게임 결정) — 게임 메뉴가 있으면 애드온에서 강제하지 않기 (예: 붉은사막은 reshade.ini MaxCount=4인데도 게임 메뉴에 6x까지 노출)
  • 전제: nvngx_dlssg.dll 310.9 (합본에 동봉. 구 3.5.x 스니펫 게임은 310.9로 교체 필요). sl.dlss_g는 Streamline 2.14 동봉(최소 2.11 이상)
  • 순서: 인게임 프레임 생성 ON → 게임 메뉴의 배율(예: "생성할 프레임 개수")에서 2x → 4x 순으로 올림. 6x는 베이스 fps가 충분할 때만
  • 실측 결과: 4x 성공 — UI 잔상 없음, 프레임 성능 매우 좋음 (예: 붉은사막, 2026-09-03)

3TMO — 톤매핑 (게임별 RenoDX 모드) 선택

TMO (Tone Mapping Overhaul) — 뭐고 도움 되나?

게임별 RenoDX 톤매핑 모드입니다. HDR 톤매퍼 선택(바닐라 / 커스텀), SDR 블랙 크러시 보정, 노출·하이라이트·섀도·대비·채도 그레이딩 슬라이더, 오토 익스포저·필름 그레인·CA·샤픈·블룸·비네팅 조절, 렌더링 개선(스펙트럴 스카이, 태양/달, VRS 끄기 등)을 한 애드온에서 다룹니다. 프레임 생성이 아니라 화면 색·밝기 다듬기 담당이라 MFGUnlock과 역할이 겹치지 않습니다.

설치: 애드온 지원 켠 ReShade 설치 → renodx-*.addon64를 게임 실행 파일과 같은 폴더에 복사 → 게임 실행 → ReShade 오버레이 Add-ons 탭에서 Generic Depth·Effect Runtime Sync 끄기 → 재시작 → Home으로 설정. (예: 붉은사막 — renodx-crimsondesert.addon64 설치됨, 인게임 확인 전)

공식 출처에서만 받기: RenoDX 토론 페이지·위키·RenoDX Discord와 제작자가 올린 Nexus 페이지가 공식 경로입니다. 이 모드는 EXE를 포함하지 않으니 EXE 실행을 요구하는 배포물은 가짜(악성코드 주의) — 절대 실행 금지. (예: 붉은사막 TMO — Nexus Mods 7번 · 제작자 안내)

충돌 주의: OptiScaler·SpecialK 같은 외부 DLL 인젝션과는 충돌할 수 있다는 게 제작자 안내입니다. 같이 쓰다가 튕기면 TMO 애드온 파일 하나만 빼고 부팅해서 원인 좁히기.

4iMMERSE 셰이더 팩 선택

iMMERSE (martymcmodding) — 뭐고 도움 되나?

iMMERSE는 Marty's Mods의 ReShade 셰이더 컬렉션입니다. 포함: MXAO(고급 SSAO), Anti-Aliasing(고속화된 SMAA), Sharpen(깊이 인식 샤픈), Launchpad(법선 벡터·옵티컬 플로우 모션 벡터를 미리 계산하는 전처리).

DLSS5 NR과의 관계: DLSS 없는 게임에서 NR(Feeder 방식)을 돌리려면 합성 모션 벡터가 필요한데, Launchpad의 옵티컬 플로우가 그 공급자 역할을 합니다(1-Click-DLSS5의 Lumenite Kernel과 같은 자리).

필수는 아닌 선택 옵션입니다. 게임에 자체 DLSS가 있으면(포크 NR 경로) Feeder 방식이 필요 없고, 무DLSS 게임에서 NR(Feeder 방식)을 돌릴 때 Launchpad의 옵티컬 플로우가 유용합니다. 화질 개선 셰이더(MXAO SSAO, 깊이 인식 샤픈) 목적으로도 쓸 수 있습니다.

5문제 해결

"the model would not initialise"
모델 DLL이 카드에 맞지 않음. RTX 20/30/40이면 패치 빌드(SF-v2 등)인지 확인 — 순정 310.8.0.0은 RTX 50 전용이며 Ada에서 FAIL_PlatformError가 납니다.
"nvngx_dlssnr.dll was not found"
모델 DLL이 게임 실행 파일과 같은 폴더에 없는 것. 한 글자 차이 주의: nvngx.dll_dlssnr.dll(포워더, 110KB)와 nvngx_dlssnr.dll(모델, 158MB)을 착각하기 쉽습니다.
화면이 통째로 초록색
구버전(v0.1.1 이하)의 HDR 색 변환 문제. v0.1.2 이상으로 업데이트하세요. (HDR 모니터 유무와 무관하게 게임의 프레임버퍼 방식이 변수입니다)
프레임 생성(FG) 켠 뒤 부팅 크래시
오버레이 저장 시 FG Input/Output 조합이 게임과 맞지 않으면 크래시가 날 수 있습니다. 저장 전 FG 설정이 정상 부팅되던 조합인지 확인, 크래시 시 OptiScaler.ini의 [FrameGen] 섹션을 직접 수정(원래 값으로)하면 복구됩니다.
아무리 해도 안 되면: bin64 비우고 무결성 후 재설치 (최후 수단)
예전 모드 잔재(구 로더·ini·충돌 dll)가 remove 후에도 남아 꼬이는 사례 확인됨(실제 해결 사례 있음). 순서: 게임 bin64 폴더 내용 백업 → 비우기 → 스팀 무결성 검사 → 게임 실행 확인 → 최신 fix2 zip 1개(en/ko)만 풀기 → setup_windows.bat → FG 고르고 Save → 재시작. 무결성 후에는 게임이 vanilla인지 먼저 켜보고, 되면 그때 모드 까세요.
ReShade와 같이 쓰기
ReShade가 dxgi.dll을 점유 중이면 OptiScaler를 version.dll로 설치(공식 권장 조합)하면 공존됩니다. ReShade 애드온(RenoDX DLSS5 등)과 포크 NR을 동시에 켜면 이중 NR이 되니 둘 중 하나만 쓰세요.
