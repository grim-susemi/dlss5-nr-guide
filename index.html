0DLSS 5 Neural Rendering이 뭔가

NVIDIA가 공개한 신세대 기술로, DLSS 업스케일러가 만든 프레임 위에 신경망 모델이 미세 디테일(모공, 천 직조, 금속 표면, 나뭇잎 등)을 다시 합성해 얹는 기능입니다. 공식 지원은 RTX 50 시리즈 + 최신 드라이버이지만, 이 가이드는 OptiScaler 포크를 써서 그 이전 카드에서도 돌리는 방법을 다룹니다.

한 줄 요약: 업스케일러(DLSS)가 "커다란 그림"을 그리면, NR 모델이 그 위에 "잔손질"을 얹는 겁니다. 프레임을 부드럽게 하는 게 아니라 디테일을 합성하는 기술이라, 효과는 확대하거나 움직임 속에서 더 드러납니다.

3어떤 도구를 쓸까 — 옵티스케일러를 우선하세요

결론부터: DX12 게임이면 옵티스케일러 NR 하나로 시작하세요. 실제 사용 기준 성능 체감이 가장 좋았던 조합이고, 프레임 생성·업스케일러·오버레이까지 전부 하나에 들어 있습니다. DX12가 아닌 게임도 대부분 옵티스케일러를 유지·혼합해서 쓸 수 있습니다 — 방법은 아래 4번 섹션에 있습니다.

DLSS5 NR을 돌리는 방법은 여러 진영으로 갈립니다. 검증 결과를 신뢰도와 함께 정리합니다(2026-09-02 기준, 전부 오프라인/싱글 전용).

4내 게임에서 DLSS5가 되나? — API별 옵티스케일러 사용법

추천 원칙: 되는 한 옵티스케일러를 끝까지 쓰세요. 게임 API가 달라져도 대부분 옵티스케일러를 유지할 수 있고, 설정이나 도구만 바꾸면 됩니다.

✅ DX12 — 설치 그대로, NR 켜기. 추가 작업 없음 (체감 최고 조합).
✅ Vulkan — v0.1.2부터 네이티브 지원. 설치 그대로, NR 켜기.
⚠️ DX11 — 옵티스케일러 유지 + 오버레이 왼쪽 위 업스케일러를 "FSR 3.X w/Dx12"(또는 XeSS w/Dx12)로 변경해야 NR이 켜집니다. DLSS를 브리지로 통과시킬 수는 없어서입니다.
❌ DX9 / DX10 / 32비트 — 옵티스케일러 단독으로는 불가 → dlss5-launcher가 DXVK 등 변환기를 자동 구성해 NR을 돌립니다(이때는 옵티스케일러를 제거해 충돌을 피하세요).

"내 게임은 되나?"에 대한 답입니다. NR 자체는 DLSS가 받는 프레임이 필요하고, DLSS는 DX11/DX12/Vulkan만 지원합니다 — 그래서 오래된 API는 변환 계층이 끼어듭니다.

DX9 게임의 진실 — 어떻게 되는 건가

DLSS 자체는 DX9 입력을 받지 못합니다(NVIDIA DLSS SDK 공식: D3D11/D3D12/Vulkan만). 그래서 DX9 게임은 DXVK(D3D9→Vulkan) 또는 dgVoodoo2(D3D9→D3D11)로 먼저 번역한 뒤, 번역된 Vulkan/D3D11 프레임에 NR을 얹습니다.

  • 실측 선례 있음: dlss5-launcher가 DX9 32비트 게임 3종(Bully, Resident Evil Revelations 2 + DXVK — 1800프레임/64fps, Saints Row 2 + dgVoodoo2)에서 NR 구동을 체인 로그로 보고. DX10(Just Cause 2)도 DXVK 1.10.3 특정 구성으로 실측.
  • 단, 자체 보고: 독립 검증은 부족하고, 같은 게임도 변환기에 따라 크래시가 갈립니다(README에 크래시 비교표 존재). 게임별 시행착오를 각오하세요.
  • DXVK는 온라인 게임과 충돌 — DX9 경로는 싱글 구작용이라는 뜻이기도 합니다.
  • RTX 20/30은 패치 DLL의 FP16 경로라 비용이 큽니다 — UI가 미리 알려주는 게 정상입니다.

5준비물 3가지

① OptiScaler_DLSSNR 포크

공식 OptiScaler에 NR 패스를 통합한 빌드. GitHub Dagherbou/OptiScaler_DLSSNR · Releases에서 최신 zip 다운로드 (v0.1.2 이상 권장 — 색 매핑 수정 포함).

② nvngx_dlssnr.dll — 모델 본체 (~165MB)

NVIDIA 드라이버 패키지에 들어있는 모델입니다. 배포 금지라 zip에 못 들어있고 직접 구해서 게임 폴더에 넣어야 합니다. NVIDIA 공식 GitHub 배포처는 없습니다(공식 DLSS SDK 저장소에는 NR 미포함) — 아래가 사실상 유일한 최신 획득 경로입니다.

6설치 (10분)

  1. 게임 폴더 찾기 — 실행 파일(.exe)이 있는 폴더. Steam이면 .../steamapps/common/게임이름/bin64 같은 하위 폴더일 수 있음 (exe 옆이 정답).
  2. 포크 zip 전부 추출 — 위 ①의 zip을 그 폴더에 풉니다. OptiScaler.dll, nvngx.dll_dlssnr.dll(포워더), OptiScaler/ 폴더, setup_windows.bat가 보이면 OK.
  3. 로더 이름 선택 — setup_windows.bat 실행 → 안내에 따라 이름 선택:
    • 보통 DX12 게임: dxgi.dll (기본값)
    • 같은 폴더에 ReShade(dxgi.dll)가 이미 있으면: version.dll 선택 (ReShade와 공존하는 공식 방법)
  4. 모델 DLL 복사 — 준비한 nvngx_dlssnr.dll(~165MB)을 같은 폴더에 넣기. 파일 하나 차이 주의: nvngx.dll_dlssnr.dll(110KB 포워더, zip에 포함)과 헷갈리지 말 것.
  5. 게임 실행 → Insert 키 → OptiScaler 오버레이 → DLSS Neural Rendering → Enable 체크 → "Running — X ms per frame" 초록 글자 확인.
setup_windows.bat 주의: 이미 OptiScaler가 설치된 게임 폴더에서 실행하면 "구버전 발견 → 삭제?" 질문이 나옵니다. 지우고 싶지 않으면 No를 누르거나, 수동으로 OptiScaler.dll을 원하는 이름(version.dll 등)으로 바꾸고 bat을 건너뛰어도 됩니다. 바꾼 이름이 정답입니다.

7켜고 확인하기

  • 오버레이: Insert (기본) → DLSS Neural Rendering → Enable Neural Rendering 체크
  • Running 표시 = 가동 중. 경고 문구가 보이면: "model would not initialise" = 카드/드라이버/DLL 문제, "not found" = 파일 위치 문제
  • Keybinds에서 "Neural Rendering" 키를 지정해두면 오버레이 없이 게임 중 토글 가능 — 강력 추천
  • 효과 확인은 Compare (Side by side / Wipe) + Zoom 2.5~3배로 하세요. 풀프레임 육안 비교로는 차이가 잘 안 보이는 게 정상입니다

Save Settings 주의: 슬라이더는 즉시 적용되지만 저장은 "Save Settings" 버튼입니다. 안 누르면 재시작 시 초기화. 또한 저장 시 프레임 생성(FG) 관련 드롭다운 상태도 같이 저장되니, FG를 쓰는 게임이라면 저장 전 FG 설정이 안전한지 확인하세요(게임마다 다름 — 아래 문제 해결 참고).

9어두운 화면 노이즈 잡기 (실전 순서)

  1. Keybinds에서 NR 토글 키 지정 → 끄고/켜고 빠르게 비교
  2. Compare → Split 켜서 좌우 대조 (가장 정확한 판정)
  3. Intensity 1.0 → 0.7 → 0.5 단계적으로 하향 (즉시 적용)
  4. 그래도 심하면 Paper white 0.8 ↔ 1.2 탐색
  5. 스타일이 과하면 Style → Natural / Cinematic
  6. 디테일이 죽었다 싶으면 Detail strength 0.8~0.9
  7. 마음에 드는 값 찾으면 Save Settings 필수
참고: NR에는 전용 디노이즈 노브가 없습니다(코어링·시간축 누적은 시도 후 제거됨). 노이즈는 위 레버 조합으로만 관리합니다. 게임이 HDR로 렌더링하는 경우 v0.1.2부터 exposure texture를 읽어 색이 맞춰지므로, v0.1.2 이상 사용을 권장합니다.

10문제 해결

"the model would not initialise"
모델 DLL이 카드에 맞지 않음. RTX 20/30/40이면 패치 빌드(SF-v2 등)인지 확인 — 순정 310.8.0.0은 RTX 50 전용이며 Ada에서 FAIL_PlatformError가 납니다.
"nvngx_dlssnr.dll was not found"
모델 DLL이 게임 실행 파일과 같은 폴더에 없는 것. 한 글자 차이 주의: nvngx.dll_dlssnr.dll(포워더, 110KB)와 nvngx_dlssnr.dll(모델, 165MB)을 착각하기 쉽습니다.
화면이 통째로 초록색
구버전(v0.1.1 이하)의 HDR 색 변환 문제. v0.1.2 이상으로 업데이트하세요. (HDR 모니터 유무와 무관하게 게임의 프레임버퍼 방식이 변수입니다)
프레임 생성(FG) 켠 뒤 부팅 크래시
오버레이 저장 시 FG Input/Output 조합이 게임과 맞지 않으면 크래시가 날 수 있습니다. 저장 전 FG 설정이 정상 부팅되던 조합인지 확인, 크래시 시 OptiScaler.ini의 [FrameGen] 섹션을 직접 수정(원래 값으로)하면 복구됩니다.
ReShade와 같이 쓰기
ReShade가 dxgi.dll을 점유 중이면 OptiScaler를 version.dll로 설치(공식 권장 조합)하면 공존됩니다. ReShade 애드온(RenoDX DLSS5 등)과 포크 NR을 동시에 켜면 이중 NR이 되니 둘 중 하나만 쓰세요.

11선택 옵션 — iMMERSE 셰이더 팩

iMMERSE (martymcmodding) — 뭐고 도움 되나?

iMMERSE는 Marty's Mods의 ReShade 셰이더 컬렉션입니다. 포함: MXAO(고급 SSAO), Anti-Aliasing(고속화된 SMAA), Sharpen(깊이 인식 샤픈), Launchpad(법선 벡터·옵티컬 플로우 모션 벡터를 미리 계산하는 전처리).

DLSS5 NR과의 관계: DLSS 없는 게임에서 NR(Feeder 방식)을 돌리려면 합성 모션 벡터가 필요한데, Launchpad의 옵티컬 플로우가 그 공급자 역할을 합니다(1-Click-DLSS5의 Lumenite Kernel과 같은 자리).

필수는 아닌 선택 옵션입니다. 게임에 자체 DLSS가 있으면(포크 NR 경로) Feeder 방식이 필요 없고, 무DLSS 게임에서 NR(Feeder 방식)을 돌릴 때 Launchpad의 옵티컬 플로우가 유용합니다. 화질 개선 셰이더(MXAO SSAO, 깊이 인식 샤픈) 목적으로도 쓸 수 있습니다.

왼쪽 열 — 업스케일러와 프레임 생성

Upscalers · DLSS Settings

Upscaler (드롭다운, 왼쪽 위) 기본: 게임 설정 따름(auto)

최종 프레임을 만들 업스케일러 기술을 고릅니다. 게임이 DLSS 입력을 주면 OptiScaler가 그걸 받아서 여기서 선택한 기술로 처리합니다. 선택지: DLSS / FSR 3.X / FSR 4(RDNA만) / XeSS.

  • DLSS 유지 권장 — NR(뉴럴 렌더링)은 DLSS 출력 위에서 돌아가므로 DLSS가 아니면 NR 자체가 꺼집니다
  • AMD/인텔 카드 사용자만 FSR/XeSS가 의미 있음
Render Presets Override 기본: OFF

DLSS 내부의 품질 프리셋(모델 스타일)을 강제 지정하는 기능. ON으로 만들고 Override Preset에서 골라 Apply Changes를 눌러야 적용됩니다.

  • Latest — 가장 최신 트랜스포머 프리셋(가장 선명, 다소 무거움)
  • 바꾼 뒤 결과가 마음에 안 들면 OFF로 되돌리면 원래대로
  • 변경 시 DLSS 특성상 프레임이 잠깐 흐려졌다 돌아오는 게 정상(캐시 재적응)
Advanced DLSS Settings (▶) 위험도 높음

DLSS 초기화 플래그(IsHdr, DepthInverted, JitteredMV 등)를 개별로 강제하는 고급 영역. 잘못 건드리면 화면이 깨지거나 게임이 죽습니다 — 현재값은 붉은사막에서 검증된 조합이므로 열어보지만 바꾸지 마세요.

Frame Generation

FG Input 확정값: DLSSG via Nvngx 크래시 조합 존재

가로챈 DLSSG 호출을 실제로 처리할 엔진. Nukem's(dlssg_to_fsr3)가 FSR3-FG로 프레임을 만들어냅니다. 이 조합에서 인게임 프레임 생성 옵션도 켜져 있어야 동작합니다.

FG 배율 강제(2x/3x/4x). Default = 인게임 설정 따름. 4x는 RTX 40 이상에서만 지원되고 프레임 품질이 떨어질 수 있음.

Current DLSSG state: OFF/ON

오른쪽 열

Sharpness

Override (샤프닝 덮어쓰기) 현재 OFF

DLSS가 자체로 수행하는 샤프닝을 고정 값으로 덮어씁니다. OFF면 게임/DLSS 기본 샤프닝을 그대로 씁니다. 화면이 너무 물먹은 느낌이면 ON 후 0.8~1.0에서 시작.

Enable RCAS/DA · RCAS · Depth Aware RCAS 선택 중

RCAS = 업스케일 출력에 얹는 경량 샤프닝(AMD FSR1 계열 알고리즘). Depth Aware는 깊이 정보를 함께 써서 경계 인위감을 줄이는 방식입니다. Override OFF면 슬라이더가 회색(비활성)으로 보이는 게 정상입니다.

Enable Motion Adaptive Sharpness OFF

화면이 움직일 때만 샤프닝을 강화하는 기능(정지 화면은 약하게). 취향 옵션. Motion Adaptive Sharpness(▶) 안에 강도/한계를 개별 설정하는 항목이 더 있습니다.

Init Flags — Auto Exposure / Disable Reactive Mask 이식된 검증값

Auto Exposure(OFF): 게임이 노출 값을 주지 않는다고 가정하는 플래그. Disable Reactive Mask(ON): 게임이 만드는 반응 마스크를 끄는 것 — 시야 부분 흐림을 방지. Advanced Init Flags(▶)에는 DepthInverted, JitteredMV 등이 있으며 붉은사막에서 검증된 값이라 건드리지 마세요.

Upscale Ratio Override / Output Scaling 전부 OFF/DISABLED 유지

렌더 해상도 비율과 초과 업스케일을 강제하는 옵션. 인게임 DLSS 품질 설정에 맡기는 중이므로 둘 다 OFF가 정답. 켜면 DLSS 체인(1704x960 → 2560x1440)이 어긋나 화질이 오히려 나빠질 수 있습니다.

⭐ DLSS Neural Rendering — 슬라이더별 원리

Enable Neural Rendering 기본: OFF ON 유지

NR 마스터 스위치. 게임 중 토글용 키를 Keybinds → "Neural Rendering"에 지정해두면 오버레이 없이 즉시 끄고/켤 수 있습니다 — 어두운 장면 비교에 필수급.

Model resolution (Cost) 기본 100% · 범위 25~100%

모델이 연산하는 내부 해상도 비율. 프레임 자체는 안 줄고 모델 비용만 줄어듦. 비용은 비율의 제곱으로 변합니다(50% = 1/4 비용). 현재 6ms로 여유 있으니 100% 유지. 프레임이 부족해지면 80%까지 내려보세요.

Enlargement 기본: Matched residual 실험적

모델 결과물을 화면 크기로 확대하는 방식 선택. 기본값 유지 권장 — 다른 값은 실험 목적(개발 노트에 명시)입니다.

Detail strength TransferStrength · 기본 1.0 · 범위 0~2

모델의 그림으로 얼마나 갈아타는지. 0 = 업스케일 원본 그대로(비트 단위 동일), 1.0 = 모델 그림 채용, 2.0 = 모델 너머 과잉 보정. 디테일 체감의 핵심 레버이며 2.00은 과잉 영역이라 1.0~1.2 권장.

Colour strength ColourStrength · 기본 1.0 · 범위 0~1

0 = 게임 원본 색을 유지하고 밝기 판단만 모델에게 맡김, 1 = 모델의 색까지 채용. 0이면 효과의 절반이 사라지므로 1.00 유지 필수. 색이 이상하면 0.8로 하향.

Intensity 기본 1.0 · 범위 0~2

모델 내부 파라미터의 강도. 어두운 화면 자글거림(노이즈) 1차 조절판 — 즉시 적용. 0.5~0.6이면 노이즈가 눈에 띄게 줄고 2.0은 과잉(콘트라스트 과다).

Local structure / Local tone 기본 1.0 · 범위 0~2

디테일 구조와 톤의 세부 강도. Intensity로 해결 안 되는 미세 조정용.

Skin structure (-1 = Local 따름) · Auto skin mask

피부 렌더링 전용 구조 강도. -1은 "끔"이 아니라 "Local structure 값을 따라감"이라는 뜻. Auto mask는 피부 영역 자동 인식. 캐릭터 얼굴이 인위적으로 보일 때만 조정.

Model preset (재시작 필요) / Style (즉시)

Preset(Default/1/2/3)은 모델 생성 시 고정되어 변경하면 재시작이 필요. Style: Default(콘트라스트·조명 강조, 과채도 가능)/Natural(피부톤·톤 원본 유지)/Cinematic(광택·과처리 억제).

✅ Take the white point from the game v0.1.2 신규 — 반드시 ON

게임이 DLSS에 넘기는 exposure texture를 직접 읽어 화이트 포인트를 자동 산출합니다. 아래 초록 상태줄(Game exposure 0.0451 → white point 106.18)이 그 결과. 이 기능 덕에 HDR 게임(붉은사막)에서도 색이 정상 — 끄면 이전 버전의 초록 화면/색 중화 문제로 돌아갑니다.

Paper white (x exposure) 기본 1.0x · 범위 0.25~4x

노이즈 2차 자동 산출된 화이트 포인트에 곱하는 배율. >1이면 모델이 프레임을 더 어둡게 받아 하이라이트가 덜 극단적으로 처리되고 <1이면 반대. 어두운 화면 노이즈가 Intensity로 안 잡히면 0.8~1.2 탐색.

Highlight guard MaxRatio · 기본 2.0x · 범위 1~8x

한 픽셀이 최대로 밝아질 수 있는 배수 상한. 어두워지는 데는 제한 없음. 램프·불빛이 색색의 셀 띄로 깨지는 고장을 방지하는 가드입니다.

Working scale (Model resolution) WorkingScale · 기본 1.0

모델이 작업하는 프레임 비율. 비용이 제곱으로 줄어들지만 첫 패스가 낮은 해상도에서 시작되므로 확대 시작점의 디테일이 줄어듭니다. 성능 컨트롤이지 품질 컨트롤이 아님.

Compare · Debug view · Capture 8 frames

Compare: Before/After를 화면에서 분할 비교(Split/Wipe, 라벨 지원) — 효과 검증의 정답 도구. Debug view: 1모델 입력/2모델 출력/3변화량 20배(평평한 회색 = 모델이 아무것도 안 함). Capture: 전/후 8프레임을 dlssnr-capture 폴더에 저장.

Reset NR Feature and Clear History

NR 모델이 내부에 쌓은 이력을 초기화하는 진단용 버튼. 화면이 이상해졌을 때 눌러보면 모델 히스토리 문제인지 즉시 구분됩니다.
